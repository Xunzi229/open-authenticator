# Authenticator v1.0.9

本次更新加入 Android 客户端，并完善跨设备迁移、解锁和账号管理。桌面端功能与 v1.0.8 保持兼容，已有保险库无需转换。

## Android 客户端

- 支持 Android 8.0 及以上版本，与桌面端共用加密保险库格式和 HTTPS WebDAV 同步。
- 支持竖屏扫码、从二维码图片或备份文件导入、手动输入设置密钥；新增账号后自动上传至已配置的 WebDAV。
- 可生成与 Google 验证器兼容的迁移二维码，每张最多 10 个账号；也可显示单个账号二维码。
- 右滑账号编辑名称、邮箱和分组，左滑弹出移除确认；验证码字号加大，并可设置默认显示全部验证码。
- 支持指纹解锁、免密码进入、浅色与深色主题；设置中可查看版本、MIT 许可并检查更新。

## 下载与安装

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `.msi`、`-setup.exe` 或 portable `.zip` |
| macOS Apple Silicon / Intel | 对应架构的 `.dmg` |
| Linux | `.AppImage`、`.deb` 或 `.rpm` |
| Android | `Authenticator_1.0.9_android_debug.apk` |

Android APK 使用与先前测试包相同的固定调试签名，可直接覆盖安装同签名版本。它未通过应用商店分发。安装前建议备份加密保险库，并确认设备允许从所用来源安装 APK。

## 同步说明

首次在 Android 使用时，可通过「从 WebDAV 恢复」输入桌面端的服务器信息和相同主密码。新增账号会自动上传；编辑或移除账号后，需在设置中手动上传。同步按整库进行，不会自动合并两端同时发生的修改；拉取远程前会在本机保存加密备份。
